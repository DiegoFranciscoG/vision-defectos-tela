# Reportes del entrenamiento

Generados por `uv run fabric-inspection reproduce` (semilla 42, CPU). No se editan a mano.

- `metrics.json`: todas las métricas (validación, test, protocolo oficial de MVTec, paridad ONNX, latencias y entorno).
- `figures/`: curvas precisión-exhaustividad, matrices de confusión, distribución de puntajes y ejemplos con mapas de calor.

Las figuras con imágenes de *carpet* (`examples.png`) derivan de **MVTec AD** y se distribuyen bajo
[CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/) (MVTec Software GmbH, © 2019). Cambios: redimensionado a 256 px y superposición de mapas.
